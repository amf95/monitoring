
[Haproxy Web Source](https://www.haproxy.com/documentation/haproxy-configuration-tutorials/alerts-and-monitoring/prometheus/)

**On `/etc/haproxy/haproxy.cfg`:**
```bash
frontend prometheus
	  bind *:8405
	  mode http
	  http-request use-service prometheus-exporter if { path /metrics }
	  no log
```

**On `prometheus.yml`:**
```bash
  - job_name: '<APP>-haproxy-metrics'
    static_configs:
      - targets: ['<HAPROXY_IP>:8405']
```
